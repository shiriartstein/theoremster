TRY IT
1. Extract this ZIP completely.
2. Open Theoremster-update/site/index.html for a local game.
3. Answer the five setup questions.
4. For the geometry deck: choose The whole collection, then Convex geometry.

UPDATE YOUR GITHUB PROJECT
The ZIP contains the complete project, not just the website.
Copy the CONTENTS of Theoremster-update into your repository, replacing the
matching files. Do not nest the Theoremster-update folder inside the repo.
Keep .github/workflows/build.yml; it rebuilds and publishes on a push to main
when GitHub Pages is configured to use GitHub Actions. See README.md.

KEEP THE CARDS UPDATEABLE
Edit data/theorems.xlsx, sheet Theorems. Upload that workbook back to data/
for future card changes. The build regenerates site/cards.js automatically.
Topics and Courses determine the filters. The new cards are T276 through
T284. The review/ folder explains historical date choices and sources.
